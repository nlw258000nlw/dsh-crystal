# dsh-crystal 结晶大管家

DSH 的全能管家插件：22 项系统体检、三把自愈锁、按需插件调度、用量记账与预算报警、每日晚 21 点早报（QQ 推送）、升级参谋、一键备份回滚、桌面大肥鱼桌宠，以及一套与 QQ 机器人（qq-dsh-bridge）深度联动的能力。

## 一句话

装上之后你什么都不用管——它定期体检，红了自愈，坏了熔断，钱花到顶会喊你，晚上九点给你发早报，桌宠在桌面陪你说体检结果。

## 核心能力（全部已实装）

### 体检与自愈
- **doctor 体检**：22 项检查（编码/端口/SnowLuma 管道/戳供/心跳/回落/预算/版本/挂载/锁/令牌/队列/磁盘/规则/插件调度/冲突/服务发现/基线/补丁/台账……），红黄绿灰四色报告
- **-Auto 自动修**：小毛病（BOM、端口写回、心跳、回落）自动修，修前快照、修后复检
- **-Fake 假测**：不落盘演示判定，验收演练专用
- **三把锁互不依赖**：锁一 doctor 自停熔断（连 3 红 [SELF-STOP] 停止接单）／锁二 kill 开关（真杀进程，每 2 分钟看门狗）／锁三 L0 兜底盖戳接管
- **熔断留痕**：熔断/超时全进 intercepts.jsonl 拦截账，面板可查

### 规则（自由填写）
- **聊天档 10 槽 + 工作档 10 槽**：每槽一条规则，自己填自己开关，空槽不用
- 总表 crystal.json 一表生成，面板点两下改好，改前自动备份
- QQ 侧干活档每 3 条输入强制复习规则

### 记账与预算
- 每轮真实 token 用量落 usage.jsonl（DSH 真桶：输入/输出/缓存读）
- **cost.jsonl 金额入账**：真实用量 × 价目表折算，只记不改账
- 预算到顶**只报警不打断**：token 线喊一行、钱线直接推 QQ（[BUDGET-PUSH]，每天最多一次）
- 按插件分账视图（crystal bill）

### QQ 机器人联动（代码在桥里，8 项全在跑）
1. **红警直推**：体检出红，30 分钟节流内直接推脑公私聊
2. **每日早报**：晚 21:00 自动推 QQ（体检/用量/欠债/端口/今日黄历）
3. **谁叫过我**：唤醒原因进早报与面板
4. **拦截账**：发送被拦（令牌失效/工具未启用）每笔留痕
5. **令牌自愈**：agent 令牌失效时，带有效控制台头的请求自动放行 + [TOKEN-SELFHEAL] 留痕
6. **群聊关键词激活插件**：群里说「查插件接口」自动拉起对应插件（按需秒醒）
7. **工作模式全自动启停**：说「工作」→ 工作插件自己开、聊天插件自己关；说「聊天」→ 反过来
8. **SnowLuma 掉线口令**：体检给出口令化恢复步骤

### 管家
- **按需调度**：插件三档 demand（常驻/按需/停用），72 小时租约自动关
- **缺失插件检测**：面板显示哪些能力插件没装 + 用途 + 一键装提示
- **待办欠债**：读 dtodo 三轨，未完成/逾期进早报
- **升级参谋**：升级前五检（版本对齐/备份新鲜/bundles 台账/桥备份/doctor 终检）
- **一键备份回滚**：crystal backup / rollback，回滚只认全绿快照+回滚后复检
- **服务发现**：真 GUI 端口指纹识别，端口漂移自动重同步

### 桌宠
- 透明置顶大肥鱼小窗，右下角陪着你
- 会说话：体检红绿、今日用量、早安晚安（静音时段只动嘴）
- 面板开关 + 频率可调；重启后自动出现（登录自启）

### 面板（侧栏「结晶」）
- 总览四卡（红黄绿灰）+ 一键体检/备份/回滚预演
- 体检明细、规则全文（双档 10 槽）、插件台账、管家数据、命令速查、设置区
- 保存即生效，改前自动备份

## 命令速查

```
crystal status   家底一眼看完
crystal doctor   22 项体检（-Auto 自动修）
crystal build    -Check 只查 / -CheckPatches 补丁漂移 / -Baseline 基线
crystal bill     按插件分账（只汇总不改账）
crystal dues     欠债清单
crystal fortune  今日黄历
crystal keywords 关键词激活地图
crystal pet      start/stop/status 桌宠
crystal backup   一键备份
crystal rollback 回滚（只认全绿快照）
crystal upgrade  升级前五检
crystal check    总表一致性检查
crystal pluginctl 插件开关台账
```

## 安装

双击 `install.ps1`（先 `-DryRun` 演练），或 DSH CLI：`dsh plugin --profile desktop add link:<插件目录>`。

## 常见问题

- 面板白屏？刷新页面（F5）；日志在 `data\crystal\alerts.log`
- 想改配置？面板「结晶」或直接改 `crystal.json`（改前自动备份）
- 换电脑？`install.ps1` 会按 crystal.json.template 渲染本机路径
