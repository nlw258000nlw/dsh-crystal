# dsh-crystal 原理页

## 能做什么
- 体检 22 项：端口真伪、JSON 编码、锁三处、心跳、插件清单、挂载、预算、规则……
- 记账：桥侧真实 usage（cacheMiss/input/output）→ cost.jsonl → 日预算 12 元 / 5 亿 token 顶格提醒
- 备份/回滚：整机关键件一次快照，回滚预演只读不落地
- 按需调度：插件需求档 + lease 72h 自动关 + 每日扫描到期软关
- 记忆三件：3 天窗体检（只标不删）、建议箱、月度账本
- 桌宠：常驻窗口，气泡+语音+右键九项，状态灯四色
- 双档：聊天档只禁跑代码/写文件/改配置，干活档全开只禁发消息

## 不能做什么
- 不能碰账号密码钱扫码；不替你对外发布
- 不能在没有桥的机器上做 QQ 联动（腾讯无官方接口，桥=本地中间件）
- 不能替你做决定：删除清单、大改动一律先问主人

## 背后原理
- 数据流：桥（bridge.js）写 usage.jsonl / work-mode.json / 事件 → 插件脚本读 → 面板 client.js + 桌宠展示
- 判定链：`crystal.ps1` 是总入口，`doctor.ps1` 是 22 项体检，`fault-dictionary.json` 是故障字典（fault id 与 doctor 引用逐字一致）
- 三锁：lock1 同错 3 次 120s 自停、lock2 kill 文件硬停、lock3 心跳 6h
- 路径：`detect.ps1` 探目录 → `data\detected.json` → crystal.json paths 覆盖（后者优先）

## 责任边界
- 体检说绿=当时那一项过；说黄=还能跑但要看；说红=列了修法，修不修人定
- 自动修只做白名单 4 项（bom-truth / gui-port / fallback / baseline-stale），snowluma-pipe 是 manual
- 一切改动留痕可回滚：.bak-<时刻> + 改动记录
