# 阶段验收单模板（六段 + 后路演练格）

## 一、范围与交付
- 本段动了哪些文件、新增哪些、改哪些（逐条列路径）。

## 二、实测证据
- 按验收口径逐条：做了什么、命令、关键输出/文件路径、行数或字节数（可复查）。

## 三、必测三件
- 三假故障指位 / 外盖戳断供灰行不自补 / 冻结只诊断不修（段二口径）；
- 后路三件事 / 故障不外溢 / 三道锁独立 / 配置分家与坏配置默认值（段三口径，按对应 CR）。

## 四、异常与冻结口径
- 本轮哪些故障红了、哪些冻结了、为什么；统计口径（未解决红=最后级别 RED）。

## 五、遗留与边界（未做项）
- 留给下一段或 P1 的，逐条写「留给谁」。

## 六、回滚点
- 动过的文件列表、退哪一版、回滚命令；现网六件是否零改动。

## 后路演练格（每段必填，没真跑=没有）
- 演练了什么：______
- 证据在哪（日志行/文件）：______
- 结果：______

- 保鲜判据（第 14 检 baseline）：render-baseline.json builtAt 超 24 小时判 YELLOW；-Auto 只刷自家 F:\crystal\data\render-baseline.json，现网六件一个字节不许写。
