# dsh-crystal 能力页

> 版本：v1001（2026-11-19 建档）；对外发布版本号由主人定夺后再改这里。

**一句话**：DSH 大管家全能插件——体检、记账、备份、按需调度、桌宠、记忆三件套、QQ 桥联动，一个插件全包。

## 用途
- 让小鱼（DeepSeek 智能体）看得见自己：端口、档位、花销、插件死活、红黄绿灰。
- 让它能自救：一键备份、回滚预演、故障复位、插件启停、租期自动关。
- 让主人管得住：干活/聊天双档、每 N 条强制复习规则、红警上 QQ、桌宠冒泡。
- 装到别人电脑也能用：目录全自动探测，不做本机写死。

## 命令速查（CLI = scripts\crystal.ps1）
status · detect · check · doctor · build · rollback · version · where · reset-melt · plugins · receipts · pluginctl · show · daily · timeline · upgrade · backup · pet · bill · dues · fortune · mem · intercepts · keywords · count
（26 条，`crystal.ps1 -Verb <动词>` 调用；`status -Arg1 json` 直出机器可读 JSON）

## 主要路径（全部可探测、可覆盖）
- 插件根：`<装哪是哪>/dsh-crystal`（detect.ps1 自动找）
- 运行数据：`%LOCALAPPDATA%\crystal\data`（crystal.json paths 可改）
- 备份根：`F:\备份`（本机习惯；别人机器自动探测或改 paths）

## 开关（crystal.json 可改，改前自动备份）
- 档位：chat / work，触发词、注入规则、工具拦截全可配
- 桌宠：enabled / size / intervalMin / voice / silent 时段
- 复习：rules-review.json 的 every（1-20，默认 3 条）
- 插件：plugins 需求档位（always / on-demand）+ lease 72h 自动关

## 权限与安全
- 不碰账号、密码、钱、扫码；外发 QQ 消息默认要主人点头
- 删除/大动作先备份留 .bak-<时刻>；体检只诊断，自动修只动白名单 4 项
- QQ 桥是可选联动：不装桥，其余功能照常

## 日志与排障
- 体检日志：data\crystal\alerts.log（[RED]/[YELLOW] 行含原因与修法）
- 医生状态：data\crystal\doctor-state.json；故障字典 data\crystal\fault-dictionary.json（22 项，每条带 detect/fix/verify）
- 挂了先跑 `crystal.ps1 -Verb doctor`（-Auto 自愈），再不行 `reset-melt <fault-id>`
- 改动留痕：`F:\系统维护\改动记录.md`（主人本机习惯；文档不绑定路径）
